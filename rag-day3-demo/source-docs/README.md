# 재현용 은행법 문서

강사 또는 리뷰어가 동일한 데이터로 RAG 파이프라인을 확인할 수 있도록 사용한 원문 5개를 보관한다.

1. 현행 「은행법」
2. 현행 「은행법 시행령」
3. 시행령 입법예고 보도참고자료
4. 시행령 개정문·개정이유
5. 은행 신규대출 금리부담 완화 시행안내

백엔드와 프론트엔드를 실행한 다음, 왼쪽 지식 베이스 패널에서 이 폴더의 PDF/TXT 5개를 모두 선택해
비교 기준은 `TOKEN`, 청크 크기 `400`이다. 제출 시연에는 조문 경계를 보존하는 커스텀 `LEGAL`,
청크 크기 `1400자`를 권장한다. 인덱스는 PGVector에 저장되므로 최초 한 번만 업로드하면 백엔드를
재시작해도 그대로 복원된다.

재현 질문 예시:

```text
은행법 제30조의3에서 대출금리에 반영할 수 없다고 정한 비용을 항목별로 모두 알려주세요.
```

```text
2026년 7월 1일 시행된 규정은 기존 대출에도 적용되나요?
```
